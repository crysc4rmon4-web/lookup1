# Sistema de diseño — LookUp

> Última actualización: Julio 2026

---

# Objetivo

Definir las reglas visuales y de experiencia de usuario que deben seguir todas las pantallas de LookUp.

El objetivo es mantener una identidad consistente entre la aplicación web y móvil.

---

# Filosofía

LookUp debe transmitir:

- Simplicidad.
- Rapidez.
- Cercanía.
- Modernidad.
- Confianza.

La interfaz debe desaparecer para que el usuario se centre en descubrir personas.

---

# Principios de diseño

- Mobile First.
- Interfaces limpias.
- Poco texto.
- Mucho contenido visual.
- Navegación intuitiva.
- Una acción principal por pantalla.
- Evitar sobrecargar la interfaz.

---

# Componentes

Todos los componentes deberán ser:

- Reutilizables.
- Accesibles.
- Consistentes.
- Tipados.
- Independientes.

---

# Espaciado

Utilizar la escala oficial de Tailwind.

Evitar valores arbitrarios salvo casos excepcionales.

---

# Tipografía

Priorizar la legibilidad.

Jerarquía clara mediante tamaño y peso.

Evitar bloques largos de texto.

---

# Color

El color debe utilizarse para:

- Guiar acciones.
- Mostrar estados.
- Destacar información importante.

Nunca únicamente como decoración.

---

# Iconografía

Utilizar una única librería de iconos en todo el proyecto.

Los iconos deben reforzar la comprensión, no sustituir el texto.

---

# Animaciones

Las animaciones deben ser:

- Cortas.
- Suaves.
- Funcionales.

Nunca deben ralentizar la interacción.

---

# Responsive

Toda pantalla debe funcionar correctamente en:

- Móvil.
- Tablet.
- Escritorio.

---

# Accesibilidad

Obligatorio:

- Navegación por teclado.
- Contraste suficiente.
- Etiquetas accesibles.
- Estados de foco visibles.

---

# Regla principal

Si un componente rompe la consistencia visual del resto del producto, debe rediseñarse antes de incorporarse.
